# muse-guard

When Meta's coding agent can't do a task honestly, it asks you
instead of faking it, and an independent checker proves it.

## What it is

A hackathon project exploring honest task handling for Meta's coding agent.
An independent checker will verify outcomes and surface when human input is needed.

## Status

Work in progress.

Built during the Meta Global AI Developer Hackathon
(Oct 26 - Nov 4, 2026).
