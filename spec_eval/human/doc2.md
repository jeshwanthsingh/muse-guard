Package room rules for our building

Each package gets one action when it's logged at the desk.

Honestly most of these are just Amazon boxes, but we have to be
consistent.

If it's perishable and the resident is away, return it to the sender.

If it's perishable and the resident is home, notify the resident
right away.

For anything that isn't perishable: if it needs a signature, hold it
at the front desk.

Non-perishable packages that don't need a signature go in a locker,
unless they're oversized. Oversized ones get held at the desk too.

The desk only knows: is it perishable (yes/no), is the resident away
(yes/no), does it need a signature (yes/no), and is it oversized
(yes/no).
